# 작업 폴더 지침

이 폴더에서 작업할 때 Claude는 아래 규칙을 따른다.

## "시작하자" 또는 새 작업을 시작할 때
1. `노하우.md`를 읽고 이번 작업에 적용한다.
2. `피드백.md`에서 `상태: 미반영`인 항목을 읽고 반영한다. 반영한 항목은 `상태: 반영됨`으로 바꾸고,
   계속 쓸 만한 요령은 `노하우.md`에 한 줄로 옮긴다.
3. `재사용/지시문/`에서 이번 작업과 비슷한 지시문이 있으면 먼저 알려주고 쓸지 묻는다.
4. 무엇을 반영했는지 세 줄 이내로 알려준다.

## 작업 중
- 파일 읽기는 `자료/`, 결과 저장은 `결과물/`에 한다.
- `자료/`의 파일은 수정하거나 삭제하지 않는다.
- 판례 번호, 조문, 출처, 숫자는 "원문 확인 필요"라고 표시한다.
- 확실하지 않은 내용은 추측하지 말고 확실하지 않다고 말한다.
- 실명, 주민번호, 연락처 같은 개인정보가 보이면 작업 전에 알려준다.

## "마무리하자" 또는 작업이 끝날 때
1. **작업일지**: `작업일지/YYYY-MM-DD 작업이름.md`에 요청 내용, 만든 결과물, 잘 안 된 점을 기록한다.
2. **노하우**: 이번에 새로 알게 된 요령이 있으면 `노하우.md`에 한 줄씩 추가한다. 이미 있는 내용과 겹치면 합친다.
3. **지시문**: 최종적으로 잘 된 지시를 다시 쓸 수 있게 정리해서 `재사용/지시문/작업이름.md`에 저장한다.
   바뀌는 부분은 [대상], [기한]처럼 빈칸으로 둔다. 같은 이름이 있으면 더 나은 쪽으로 고친다.
4. **견본**: 결과물이 좋았으면 개인정보를 지운 견본을 `재사용/견본/`에 저장할지 묻는다.
5. **스킬 제안**: 같은 지시문이 세 번 이상 쓰였으면 스킬로 만들지 묻는다.
6. 남긴 것을 목록으로 짧게 알려준다.

## 언제나
- 일지, 노하우, 지시문, 견본에는 실명·주민번호·연락처 같은 개인정보를 적지 않는다.
