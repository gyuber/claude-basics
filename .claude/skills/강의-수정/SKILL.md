# 강의 수정 절차

먼저 저장소 루트 `CLAUDE.md`의 원칙을 확인한다. 아래 순서를 빠짐없이 지킨다.

## 1. 내용 확인
- Claude Code 기능이면 공식 문서(code.claude.com/docs, support.claude.com)에서 확인한다. 메뉴 이름, 경로, 우선순위, 제한을 그대로 옮기고 📖 링크를 단다.
- 어느 편에 넣을지 정한다. 새 편이면 번호를 정하고 README 목차, 다른 편의 "(N편)" 참조, FAQ(12편)까지 맞춘다.

## 2. 강의 본문 (`기초/*.md` 또는 `작업방식/*.md`)
- 설명 → **그림** → **예시 대화(🙋/🤖, 법률 실무)** → 표 순서로 쓴다.
- 예시 대화 아래에는 이 문장을 둔다:
  `*💬 예시 대화와 재현 그림은 이해를 돕기 위해 만든 것이에요. 사건, 이름, 숫자는 모두 가상이고 실제 답은 조금 다를 수 있어요.*`
- 새로 생길 만한 질문은 `기초/12-자주-묻는-질문.md`에 Q/A로 추가한다.

## 3. 재현 그림 (필요하면)
- `_tools/scenes/make_scenes.py`의 `S['이름'] = page(...)`로 장면을 추가한다. 도우미: `side()`(사이드바, `groups=`로 폴더별 묶음), `bar()`(입력창 아래 줄), `me()`, `ai()`, `.call`(주황 설명표), `.pop`(메뉴), `.perm`(허락 요청), `.toast`(알림).
- 화면 이름은 실제 한국어 UI를 쓴다 (CLAUDE.md 6번).
- `_tools/scenes/shoot.sh` 실행 → `images/scenes/이름.png`를 **직접 열어 보고** 설명표가 글자를 가리지 않는지 확인한다.

## 4. 슬라이드 (`slides/_src/sections.html`)
- 같은 내용을 슬라이드로 옮긴다: 설명 장 + 예시 장(`.chat` 말풍선 또는 표) + 재현 그림 장(`.boxes.shot.big`, `SCN/이름.png`).
- 블록 클래스와 디자인 규칙은 `slides/_src/NOTES.md`. 낙서(`data-scrib`)는 섹션 첫 장에만, 별·밑줄(`.mk`, `.mk.st`)은 결론 줄에만 아껴 쓴다.
- 목차(`이번 이야기`)가 바뀌면 행도 고친다.
- 빌드: `python3 slides/_src/build.py <임시폴더>` → `slides/index.html`과 `<임시폴더>/artifact.html`
- 캡처 검사: `_tools/shoot_slides.sh <바뀐 장 번호들>` → 나온 sheet 이미지를 **직접 열어서** 넘침, 겹침, 꼬리말 침범이 없는지 본다. 장 번호는
  `grep -o '<h2>[^<]*</h2>' slides/index.html | nl` 의 번호 + 1 (표지에는 h2가 없음).

## 5. 마무리
- `python3 _tools/fix_md_tables.py`
- 커밋 메시지는 한국어로 무엇을 바꿨는지. 푸시.
- `_tools/check_pages.sh` → `TABLE MISMATCH`가 없고 슬라이드 장 수가 맞는지 확인.
- Claude 페이지(아티팩트)로도 슬라이드를 배포하고 있다면, 빌드된 `artifact.html`과 `images/`, `scenes/` 파일을 같은 주소로 다시 발행한다.

## 6. 보고
- 무엇을 넣었는지(강의 몇 편, 슬라이드 몇 장, 그림 몇 장), 확인한 것, 확인 못 한 것(추측한 메뉴 이름 등)을 짧게 알린다.
