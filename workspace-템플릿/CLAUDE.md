# 작업 폴더 규칙

이 폴더는 법률 문서·엑셀 작업용이다. 사용자는 개발자가 아니므로 쉬운 한국어로 답하고, 기술 용어나 명령어 설명은 하지 않는다.

## "시작하자" 또는 새 작업을 시작할 때
1. `git pull`로 최신 내용을 받는다. 실패하면 이유를 쉬운 말로 알려주고 작업은 계속한다.
2. `노하우.md`를 읽고 이번 작업에 적용한다.
3. `피드백.md`에서 `상태: 미반영`인 항목을 반영한다. 반영한 항목은 `상태: 반영됨`으로 바꾸고, 계속 쓸 요령은 `노하우.md`에 한 줄로 옮긴다.
4. `재사용/지시문/`에서 이번 작업과 비슷한 것이 있으면 먼저 알려주고 쓸지 묻는다.
5. 무엇을 반영했는지 세 줄 이내로 알려준다.

## 작업 중
- 파일 읽기는 `자료/`, 결과 저장은 `결과물/`에 한다. 결과 파일 이름은 `YYYY-MM-DD 내용.확장자`.
- `자료/`의 파일은 절대 수정하거나 삭제하지 않는다.
- 판례 번호, 조문, 출처, 숫자는 "원문 확인 필요"라고 표시한다.
- 확실하지 않은 내용은 추측하지 말고 확실하지 않다고 말한다.
- 실명, 주민번호, 연락처 같은 개인정보가 보이면 작업 전에 알려준다.

## "마무리하자" 또는 작업이 끝날 때
1. **작업일지**: `작업일지/YYYY-MM-DD 작업이름.md`에 요청 방식, 만든 결과물 파일 이름, 잘 안 된 점을 적는다. 사건 내용·개인정보는 적지 않는다.
2. **노하우**: 새로 알게 된 요령을 `노하우.md`에 한 줄씩 추가한다. 겹치면 합친다.
3. **지시문**: 잘 된 지시를 `재사용/지시문/작업이름.md`로 정리한다. 바뀌는 부분은 [대상], [기한]처럼 빈칸으로 둔다.
4. **스킬 제안**: 같은 지시문이 세 번 이상 쓰였으면 `.claude/skills/`에 스킬로 만들지 묻는다.
5. `git add`는 `노하우.md 피드백.md 작업일지 재사용 .claude` 만 한다. 커밋 후 `git push`.
   push 전에 올라갈 파일 목록에 `자료/`나 `결과물/`이 있으면 멈추고 알린다.
6. 남긴 것을 목록으로 짧게 알려준다.
