tmux05

2. tmux

왜
  • 한글 입력 중에는 prefix 뒤 키가 안 먹음
  • WSL 을 다시 켜면 세션이 사라짐
  • Claude 작업이 끝난 창을 찾아다녀야 함
효과
  • 한글 상태에서도 같은 키로 동작
  • 10분마다 자동 저장, 켜면 복구
  • 끝난 창은 빨간색, prefix b 로 이동
Why / Effect06

tmux 구조: 세션

프로젝트마다 세션 하나, 저장과 복구는 tmux-resurrect, tmux-continuum 이 알아서

3. vim

왜
  • 자동완성을 Ctrl+n 으로 직접 불러야 했음
  • Go 파일 저장 때 import 정리가 따로
  • 컴퓨터마다 vim 버전이 다름 (8.2, 9.1)
효과
  • 입력하면 바로 자동완성 팝업 (vim 9.1)
  • 저장하면 gopls 가 포맷, import 정리
  • 옛 vim 은 알아서 기본 소스로
