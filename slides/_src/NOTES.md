# chalkboard

교수님이 칠판에 분필로 쓴 느낌. 먹색 칠판에 지운 자국, 분필 흰 글씨와 색분필 강조, 아래에 분필 받침. 나무 테두리는 없다.
참고 이미지: 먹색 칠판 템플릿 세 장 (분필 받침과 스펀지 지우개, 파란 두 줄 밑줄, 산 낙서), 초록 칠판 개회식 템플릿.
첫 사용: 2026-11-04 발표 덱. `template.html` 은 그 덱과 장 구성, 스타일이 같고 본문만 회사와 무관한 dotfile 예시로 바꾼 것 (19장).

## 재료
- 폰트: h1, h2 `Nanum Pen Script`, h3, 라벨, 숫자 `Gamja Flower`, 본문 `Gaegu` (Google Fonts). 본문 27px, h2 `clamp(56px, 6.6vw, 92px)`, 표지 h1 `clamp(110px, 15.5vw, 240px)`
- 그림: rough.js 4.6.6 (`cdn.jsdelivr.net/npm/roughjs@4.6.6/bundled/rough.js`) + SVG 필터 `#chalk`(선 가루 질감), `#chalk-text`(제목, 큰 숫자 질감)
- 칠판: 각 `.slide` 배경에 3단 radial(`--board-hi`, `--board`, `--board-lo`) + 잡티 노이즈 타일 + 지운 자국(가로로 늘인 저주파 노이즈). 둘 다 data URI SVG 라 외부 이미지 없음
- 받침: `.ledge` (fixed, 아래 22px), 분필 다섯 자루와 스펀지 지우개는 CSS 로만
- 색 (분필): 흰 `#F3F1E7`, 하늘 `#8ED1FC`, 분홍 `#FF9EC4`, 노랑 `#FFE380`, 민트 `#B2F2BB`, 빨강 `#FF8A8A`, 라벤더 `#D0BFFF`
- 초록 칠판으로 바꾸려면 `--board`, `--board-hi`, `--board-lo` 를 `#2A5B45`, `#316A51`, `#1E4433` 으로, `--ink-3` 을 `#93AE9F` 로
- 박스는 CSS 테두리 없이 투명, `draw()` 가 요소 크기를 재서 분필 선을 뒤에 그린다 (crayon 과 같은 방식, seed 고정)

## 블록 (클래스)
crayon 과 클래스 이름이 같아서 crayon 덱 본문을 그대로 옮겨와도 그려진다. 그리는 모양만 다르다.

| 클래스 | 용도 | 그려지는 모양 |
|---|---|---|
| `.slide.cover` + `h1 dotfile<br><span>스케치</span>` | 표지 | 제목 왼쪽, 첫 줄 옆 노란 반짝이, 오른쪽에 초록 산 낙서 하나, 구석에 흐린 전구와 `</>` |
| `.slide[data-scrib="checklist|docs|anvil|flask|chart|robot"]` | 칠판 낙서 | 제목 오른쪽 빈 곳에 흐린(30%) 그림 하나, 강조만 노랑. 목차는 클립보드, 문서는 종이 더미, 도구는 모루와 망치, 실험은 플라스크, 현황은 올라가는 막대, 봇은 로봇과 돋보기. 자리가 좁으면 알아서 안 그림 |
| `span.mk`, `span.mk.st` | 결론 한 줄 강조 | 하늘색 두 줄 밑줄, `.st` 는 왼쪽에 서툰 별도 |
| `h2` | 슬라이드 제목 | 하늘색 분필 두 줄이 엇갈리는 밑줄 |
| `.tt` | 제목 아래 인용 한 줄 | 펜 손글씨, 회색 |
| `.rows > .row` (`.n`, `h3`, `.r`) | 목차 | 흰 분필 박스, 번호는 노란 동그라미 |
| `.why > div` + `.why > .fx` | 왜 / 효과 | 왼쪽 흰 박스, 오른쪽 분홍 박스 + 옅은 분홍 칠 |
| `.q`, `.lbl`, `small.k` | 라벨 | 색분필 글씨 + 같은 색 동그라미 (분홍, 하늘, 노랑, 민트 돌려쓰기) |
| `.boxes.b2/b3/b5 > div`, `.on` | 단계, 카드 | 흰 박스, `.on` 은 노랑 박스 + 옅은 노랑 칠 |
| `.trk > div[data-pct]` (`.pct`, `.gauge`), `.meta` | 진행률 카드 | 흰 박스 아래 하늘 막대, `.meta` 는 막대 없이 회색 점선 |
| `.figs > div` (`.v`, `.k2`) | 숫자 | 흰 박스, 첫 칸 숫자 노랑 |
| `.cat > div` (`.cn`, `h3`, `.use`) | 카테고리 3개 | 하늘, 민트, 분홍 박스 |
| `.ba > div + div` (`.lbl`, `.res`, `b`) | 전 vs 후 | 왼쪽 흰 박스, 오른쪽 분홍 박스, `b` 는 노랑 글씨 |
| `.src span` | 소스, 단계 칸 | 흰 점선 박스 |
| `.bar > i.seen / i.blind` | 비율 막대 | 글이 올라가면 옅은 칠, 빈 막대는 분필 빗금 (하늘 / 빨강) |
| `.cmp` (`.t`, `.pair > .bar`, `b`) | 전후 막대 짝 | 빨강(전), 하늘(후) 빗금 막대 + 오른쪽 값 |
| `.repos > i` | 칸 그리드 | 흰 분필 작은 칸 |
| `.tblw > .tbl` | 표 | 흰 박스, 머리글 노랑, 줄은 점선 |
| `.diagram svg` (`rect.s-box`, `rect.s-inv`, `path.s-l`, `path.s-l.d`, `path.s-l.n`) | 흐름도 | 박스는 하늘, 분홍, 민트, 주황 돌려쓰기, `s-inv` 는 노랑 박스 + 옅은 노랑 칠, `.d` 는 라벤더 점선, `.n` 은 화살촉 없음 |
| `.pg` | 꼬리말 (왼쪽 라벨, 오른쪽 번호) | 받침 위 |

## 사용자 반응 (2026-11-04)
- 좋아함: 먹색 칠판, 테두리 없음, 아래 분필 받침
- 처음엔 초록 칠판 + 나무 틀로 만들었다가 참고 이미지를 더 받고 먹색, 테두리 없음으로 바꿈
- 싫어함: 표지 장식이 많은 것 (깃발 두 줄, 덱 숫자 낙서, 원그래프, 막대 낙서) → "너무 복잡" → 제목, 반짝이 하나, 산 낙서 하나만
- 글자 뒤 빗금 금지 (crayon 때 "눈이 아파"). 글이 올라가는 칸은 같은 색 옅은 칠(solid, 낮은 alpha), 빗금은 글 없는 막대에만
- 서툰 별, 밑줄, 낙서는 "아주 조금만" 넣기를 원함. 낙서는 목차와 섹션 첫 장에만 하나씩, 별과 밑줄은 덱 전체에서 결론 네 줄 정도
- 낙서는 참고 이미지의 수학 공식, 도형을 그대로 쓰지 말고 **본문에 어울리는 그림**으로 (스케치노트 기본 어휘: 종이 = 문서, 체크 = 테스트, 돋보기 = 리뷰, 전구 = 아이디어)

## 주의
- `.slide` 에 칠판 배경이 있어서, `z-index: -1` 자식은 `.sk`(z-index 0) 같은 쌓임 맥락 안에서만 보인다. 밖에 두면 배경 뒤로 숨는다.
- 1440x900 에서 `.b5` 두 줄(카드 10개) 장이 거의 꽉 찬다. 내용 늘리면 `shot.sh` 로 꼬리말이 받침 위에 보이는지 확인.
- `.diagram` 글자 크기는 SVG 좌표 기준 (`.s-t` 30, `.s-s` 21, `.s-lab` 27 유지).
- 필터가 제목, 큰 숫자, 모든 분필 선에 걸려 있어 슬라이드가 아주 많으면 처음 그릴 때 조금 느릴 수 있다.
