# 03. 이어서 다듬기

결과가 마음에 안 들어도 **처음부터 다시 묻지 마세요.** 같은 대화에서 고쳐 달라고 하면 됩니다.
한 번에 완벽한 답보다, 두세 번 다듬는 게 더 빨라요.

## 자주 쓰는 말 모음 (이게 명령어예요)
| 하고 싶은 것 | 이렇게 말하기 |
|---|---|
| 줄이기 | "A4 한 장으로", "세 줄로 요약" |
| 쉽게 | "의뢰인이 읽을 수 있게 쉬운 말로" |
| 정리 | "표로 정리해줘", "번호 매겨서" |
| 근거 | "근거 조문·출처를 옆에 달아줘" |
| 검토 | "반대편 입장에서 반박해봐" |
| 정직하게 | "확실하지 않은 부분은 표시해줘" |
| 부분 수정 | "3번만 다시 써줘, 나머지는 그대로" |
| 질문 먼저 | "시작하기 전에 필요한 걸 먼저 물어봐" |
| 저장 | "이대로 `결과물/`에 Word로 저장해줘" |
