# 07. 꼭 지킬 것

1. **인용·숫자는 원문으로 확인**
   판례 번호, 조문, 출처, 계산 결과를 그럴듯하게 틀릴 수 있어요. 원문을 확인하기 전에는 쓰지 마세요.
2. **최신 정보는 따로 확인**
   최근에 바뀐 법이나 사실은 모를 수 있어요. 웹 검색을 켜거나 직접 확인하세요.
3. **원본은 연결하지 않기**
   Cowork는 파일을 고치거나 지울 수 있어요. 항상 사본으로 작업하세요.
4. **민감한 정보는 지우기**
   실명, 주민번호, 연락처는 A·B로 바꾸거나 지우세요. 설정에서 대화가 학습에 쓰이는지도 확인하세요.
5. **확인 요청은 읽고 허락하기**
   Claude가 "이 파일을 수정할까요?"라고 물으면 무엇을 바꾸려는지 보고 허락하세요.
6. **최종 판단은 내가**
   Claude는 초안까지만. 책임은 사람에게 있어요.
